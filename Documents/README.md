# Documents

Reference material and plans for Cline (course slide "Cline — @ files as context").

- Put reference PDFs here (e.g. `Project Charter.pdf`, `Figma.pdf`), then `@`-mention them in a Cline Plan prompt.
- Plans created with the `/create-plan.md` workflow are saved in `Documents/plans/` as `KM-<number>-<short-name>.md`.

Example Plan prompt:

> Use @/Documents/Project Charter.pdf and @/Documents/Figma.pdf to create a plan for KM-94, including any tech stack changes. Save the plan in @/Documents/plans.

Large PDFs use a lot of tokens on the Gemini free tier. Mention only the ones the task needs.
